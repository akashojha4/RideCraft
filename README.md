# RideCraft

An interactive platform that teaches how a geared motorcycle works and how to ride one.

Built with React 19, TypeScript, Vite, Tailwind CSS v4, React Router and Motion.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
npm run lint
```
